## Highlights

- **16.0x Velocity Engine:** Granular 0.1x increments up to 16x with hardware pitch preservation.
- **Auto-Skip Dead Air & Silence:** Real-time Fast Fourier Transform (FFT) analysis detects pauses and speeds through them automatically (saves ~25% viewing time).
- **600% Volume Gain Amplifier:** Web Audio API GainNode safely amplifies faint lectures and whispered Zoom meetings.
- **Vocal Clarity & Speech EQ:** 3kHz biquad peaking filter highlights human speech intelligibility while attenuating HVAC and low-frequency hum.
- **1-Click High-Res Frame Capture:** Snap clean presentation slides and diagrams directly to PNG without player UI.
- **A-B Infinite Segment Looper:** Loop any segment between Point A and Point B repeatedly for studying.
- **Time Saved Tracker:** Live telemetry of real hours and minutes saved right in your popup.

## Installation (Unpacked)

1. Clone or download this repository.
2. In Google Chrome, navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the `05-sonicspeed-pro` folder.
5. Open `demo-test.html` or YouTube/Netflix to start accelerating playback.
